XBeach model for Ft. Meyers Beach, FL and Hurricane Ian.
Working with Don Slinn to nest XBeach (this work) in ADCIRC/SWAN. 


A description of directories is below.
- example: directory containing xbeach examples. Includes "Delilah" model and example of using OpenEarth's xbeach-tools. 
- models: Directory containing the xbeach models to be ran. In this directory is a python script to setup the xbeach model. Each model is setup in its own directory.
