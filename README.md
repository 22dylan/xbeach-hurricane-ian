# XBeach Hurricane Ian
Github repo containing XBeach setup scripts for simulating Hurricane Ian. 

This repo is used for both version control of model setup scripts and to keep track of my list of TODOs.

The prepared model input and resulting model outputs are not stored on this repo. 


The following directories are in this repo:
- for-linux-vm: scripts to run on a google vm; the vm is linux.
- python: directory to contain misc. python scripts to process data; some used to test python routines.
- plotting: tools for plotting and making animations. 
- xbeach: python script to setup xbeach model.
